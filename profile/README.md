# Whisp - Pure PHP SSH Server

An SSH server written in pure PHP for the best way to build SSH based PHP TUIs.

⇾ [Take a look at the docs](https://whispphp.com)


# Example Apps

Explore the [example app source](https://github.com/WhispPHP/whisp.fyi/tree/main/apps) to build and run apps on your own Whisp server:

- [World Heritage Sites](https://github.com/WhispPHP/whisp.fyi/blob/main/apps/elec.php)
